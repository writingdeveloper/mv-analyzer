# 뜬 MV와 묻힌 MV는 무엇이 다른가 — 두 도메인 극단 그룹 연구, 그리고 우리 자신의 발견 일부를 무너뜨린 교란 통제

*초안 — 2026-07-21. 관찰 연구이며 인과 주장은 하지 않는다. 본 리포트의 모든 수치는 `docs/reports/` 아래 날짜별 리포트에서 그대로 인용했으며, 여기서 재계산한 값은 없다.*

## 초록

우리는 조회수/구독자수 비율(views-per-subscriber)로 성과를 정규화했을 때, 성과가 높은 유튜브 뮤직비디오(MV)와 낮은 MV를 통계적으로 무엇이 가르는지 묻는다. 완전 로컬·재현 가능한 파이프라인(yt-dlp, PySceneDetect, librosa, ffmpeg, 로컬 비전-언어모델)으로 **두 도메인 N=100편**(보컬로이드 50, K-pop 50)에서 약 90개 측정 화면·음향·가사·패키징 지표(94컬럼)를 추출했다. 각 도메인에서 상위 25 / 하위 25 극단을 표본으로 삼았고, 비교는 Mann–Whitney U + Cliff's δ + Benjamini–Hochberg FDR로 수행했다.

보컬로이드 도메인에서는 **편집 리듬 구성개념이 압도적**이다. 샷 길이 중앙값(δ −0.79), 분당 컷 수(δ +0.72), 씬 수(δ +0.65), 컷당 비트 수(δ −0.65), 첫 15초 컷 수(δ +0.57)가 모두 q<0.05로 그룹을 가르며, 상위 그룹은 하위 대비 약 4배 빠르게 편집된다. 이 효과들은 채널 다작(prolificacy) 매칭 재분석에서 10/10 유지됐고, 거의 전부 결정론적 측정기에 기반하며(블라인드 라벨러 검증 n=52에서 유일한 VLM 기반 생존 지표인 등장인물 수는 ρ=0.80으로 통과), 하나의 잠재 요인으로 응집한다(블록 내 평균 |ρ|=0.69). 그 상관 구조는 도메인 간에 재현된다(PC1 congruence 0.96). K-pop은 **부분 재현**한다. 샷 길이 중앙값(δ −0.50)과 등장인물 수(δ +0.52)는 전이되지만 편집 템포 효과는 유의성 아래로 축소된다 — 그 도메인에서는 빠른 편집이 이미 업계 표준이라는 해석과 정합한다. 추가한 보컬로이드 중간층 표본에서 사전 등록 편집 리듬 6개 지표 전부가 하위→중간→상위 단조 gradient를 보였고(6/6, Kendall τ, 전부 q<0.005; 예: 분당 컷 5.5→17.5→23.9), 극단 그룹 대조가 dose-response gradient로 격상된다.

세 개의 추가 분석을 사전 등록했고 셋 다 **사전 설정 게이트에서 FAIL**했으며, 우리는 이를 검증된 음성 결과이자 자기교정 사례로 보고한다. (1) 사이클 1의 프리미어 공개 효과(Fisher p=0.016)는, 비-MV 통제 오염을 제거한 뒤 채널 내 매칭에서 **소멸**했다(55쌍, p=0.46). (2) 가사 반복성 가설(Nunes et al. 2015)은 약하게만 성립했고, K-pop 커버리지를 억제하던 ASR 언어필터 측정 버그를 고친 뒤(28→47) 오히려 축소됐다(압축률 δ +0.32→+0.14, q=0.43). (3) most-replayed 히트맵 리텐션의 그룹 비교는 null이었다. 우리는 이 음성 결과들 — 그리고 그것을 낳은 교란 통제 자체 — 을, 공개 100-MV 지표 데이터셋 및 100% 로컬 재현 경로와 함께 주요 기여로 제시한다.

## 1. 서론

제작자와 플랫폼은 특정 제작 선택 — 빠른 컷의 도입부, 텍스트 없는 썸네일, 프리미어 공개 — 이 MV의 성공을 "이끈다"고 흔히 단언한다. 그러나 이런 주장은 통제된 비교로 검증되는 일이 드물고, 같은 선택을 하고도 실패한 *묻힌* 영상과 대조되는 일은 거의 없다. 본 연구는 이 질문을 의도적으로 좁고 검증 가능한 형태로 던진다. **한 장르 안에서, 비슷한 채널에 공개된 영상들 중, 어떤 화면·패키징 지표가 실제로 상위와 하위 성과를 가르는가?**

성과는 조회수/구독자수 비율(`view_per_sub`)로, 즉 팬덤 규모를 어느 정도 상쇄하려는 채널 내 정규화로 조작화한다. 그리고 **극단**을 본다 — 각 도메인에서 이 비율 상위 25편과 하위 25편. 극단 그룹 설계는 고정된 라벨링 예산에서 검정력을 극대화하는 대신, 효과크기를 과대추정하고 연속 추론을 막는다는 알려진 대가를 치른다. 우리는 이 한계를 숨기지 않고 전면에 둔다(§5).

기여는 세 가지다.

1. **재현 가능한 100% 로컬 측정 방법.** 모든 단계가 소비자용 GPU 한 대에서 외부 API 없이 돈다. 의미 태그는 로컬 VLM(temperature 0, 폐쇄 어휘)에서 나오지만, 주요 효과는 전부 결정론적 측정기(씬 검출, 오디오 DSP, OCR/ASR 파생 계수)에 기반하며, 이를 블라인드 인간-모델 라벨러로 별도 검증한다.

2. **공개 2-도메인 지표 데이터셋.** `dataset/features_100mv.csv` — 화면·음향·가사·패키징에 걸친 100편 × 94컬럼, 공개 메타데이터와 파생 측정치만 포함(미디어·저작권 가사 원문 없음).

3. **검증된 음성 결과를 포함한 발견.** 우리가 적용한 모든 견고성 검사를 통과한 편집 리듬 효과, 부분 도메인 재현, 그리고 — 일급 결과로서 — 사전 게이트에서 FAIL한 세 사전등록 분석(자기 사이클 1 발견 하나가 제대로 된 교란 통제를 통과하지 못한 자기교정 포함).

우리는 **인과 주장을 하지 않는다**. "성과 높은 MV는 더 빨리 편집됐다"는 "빨리 편집하면 성과가 오른다"가 아니다. 빠른 컷·조밀한 작화·프리미어 공개는 모두 미관측 제작 투자의 프록시일 수 있다.

## 2. 관련 연구

**Hit song science.** 성공을 오디오 콘텐츠만으로 예측할 수 있는가를 묻는 계열이다. 초기 시도(예: Dhanaraj & Logan, ISMIR 2005)는 음향·가사 특징으로 분류기를 학습했고, Pachet & Roy(ISMIR 2008)의 영향력 있는 "Hit song science is not yet a science"는 콘텐츠 특징의 예측 신호가 기대보다 훨씬 약하다고 논증했다. 우리 설계는 그 회의론의 하류에 있다 — 연속 차트 성과를 콘텐츠로 예측하는 대신, 콘텐츠 특징이 사전 선택된 성과 극단을 *가르는지*를 검정하고, 살아남은 효과를 예측-인과가 아닌 서술로 다룬다.

**가사 반복성.** Nunes, Ordanini & Valsesia(2015), "The power of repetition: repetitive lyrics in a song increase processing fluency and drive market success"(Journal of Consumer Psychology)는 반복적인 가사가 더 유창하게 처리되며 시장 성과와 연관됨을 보고한다. 우리는 반복성의 언어 무관 조작화(정규화 가사 텍스트의 zlib 압축률)를 사전 등록해 이 가설을 우리 도메인에서 직접 검정했다(§4.3).

**감정 아크.** Reagan, Mitchell, Kiley, Danforth & Dodds(2016), "The emotional arcs of stories are dominated by six basic shapes"(EPJ Data Science)는 서사 감정 궤적이 소수의 형태로 군집함을 보인다. 이는 특징 평균만이 아니라 시간 구조(도입 훅, 리텐션 곡선)에 대한 우리의 관심을 동기화한다. 다만 본 연구의 가사 정서 측정은 궤적이 아니라 폐쇄 어휘 단일 태그다.

**온라인 영상 인기.** 플랫폼 인기 동역학 연구 — 예: Szabó & Huberman(2010), "Predicting the popularity of online content"(Communications of the ACM); Figueiredo, Benevenuto & Almeida(2011), "The tube over time: characterizing popularity growth of YouTube videos"(WSDM) — 는 관측된 인기가 초기 프로모션·유입 구조·시간, 즉 콘텐츠 외적 요인에 크게 좌우됨을 강조한다. 이는 우리의 채널 내 정규화와 교란 통제 재분석을 직접 동기화하며, 미관측 프로모션 한계의 틀을 잡는다.

## 3. 데이터와 방법

### 3.1 표본 설계

단위는 공개된 유튜브 MV다. 성과는 고정 수집 스냅샷 시점의 조회수/구독자수 비율이다. 각 도메인에서 큐레이션된 채널 목록으로 모집단을 열거하고, 균일한 필터(구독자 ≥ 1,000, 60~600초, 세로/Shorts 제외, 비-MV 제목 휴리스틱 제거, **채널당 최대 2편**)를 적용한 뒤, `view_per_sub` 상위 25편과 하위 25편을 두 비교 그룹으로 삼는다.

- **보컬로이드**(사이클 1): 원본 프로듀서 채널, 2025-04~2026-04 공개 신곡(171채널 열거 → 필터 → 상위 25/하위 25).
- **K-pop**(재현): 공식 아티스트/레이블 채널, 동일 파이프라인·동일 통계.

결과 공개 테이블은 `dataset/features_100mv.csv`(50 + 50편, `domain` 컬럼 구분)다. 극단 그룹 표집은 의도적이며(검정력 집중), 추론에 미치는 결과는 §5에서 다룬다.

**중간층 표본(단조성).** 극단 너머의 dose-response를 검정하기 위해, 같은 모집단에서 `view_per_sub` 40~60 백분위 보컬로이드 25편을 중간층 그룹으로 추가했다(채널 캡 동일, 극단 그룹과 무중첩) — 하위 25 / 중간 25 / 상위 25 순서로 단조성 검정에 사용한다(§4.5). 이로써 분석 영상 총계는 125편(보컬로이드 75, K-pop 50)이 되지만, 본 논문 전반의 극단 그룹 통계와 공개 데이터셋은 여전히 극단 100편(50 + 50) 기준이다.

### 3.2 파이프라인 (100% 로컬, 외부 API 없음)

| 단계 | 도구 |
|---|---|
| 수집·메타데이터 | yt-dlp + ffmpeg (deno JS 런타임) |
| 씬 경계/컷 리듬/색감 | PySceneDetect 0.7 (ContentDetector t=15) + OpenCV |
| 오디오 (BPM·키·LUFS·에너지·비트) | librosa 0.11 + ffmpeg ebur128 |
| 장면 의미 태깅 | Ollama `qwen2.5vl:7b`, temperature 0, 폐쇄 어휘 |
| 가사 — 하드자막 OCR | 동일 VLM, 하단 크롭 0.5fps (≥8라인 회복 시 사용) |
| 가사 — ASR 폴백 | demucs 보컬 분리 + faster-whisper large-v3 |
| 가사 주제/감정 | Ollama 텍스트 호출, 폐쇄 어휘 |
| 교차 동기화·훅 | 씬 × 비트 파생 계산 |

GPU 단계는 절대 동시 실행하지 않는다(16GB VRAM): ASR은 별도 프로세스로 돌고, 직전에 VLM을 명시적으로 언로드한다.

### 3.3 통계

각 수치형 지표에 대해 Mann–Whitney U 검정, 비모수 효과크기 **Cliff's δ**(|δ| ≈ 0.11/0.28/0.43 = 작음/중간/큼), 지표군 전체에 대한 **Benjamini–Hochberg FDR** q값을 보고한다. 이진 지표는 Fisher 정확검정을 쓴다. q<0.05일 때 그룹을 가른다고 해석한다. 도메인 간 비교는 *도메인 내* 상/하위 대조로만 제한한다(원 지표값의 도메인 간 직접 비교 금지) — 가사 측정 출처가 도메인 간에 계통적으로 다르기 때문이다(§5).

### 3.4 측정 신뢰도 검증

일부 지표가 VLM에서 나오므로 태그 정확도를 독립 검증했다(`docs/reports/2026-07-17-measurement-reliability.md`): 키프레임 52장(보컬로이드 26편 × 2, 층화)을 독립 상위 모델이 동일 폐쇄 어휘로 블라인드 라벨링한 뒤 파이프라인의 `qwen2.5vl:7b` 태그와 대조했다. 일치율 / Cohen's κ: mood 52% / 0.43(중간), shot_type 58% / 0.38(낮음), style 75% / 0.52(중간), 등장인물 수 정확 85% / ±1 이내 94% / ρ=0.80(높음). 결과가 우리 발견에 미치는 영향(§4.1): 사이클 1 유의 효과 10개 중 9개는 VLM 신뢰도와 무관한 결정론적 측정기 기반이며, 유일한 VLM 기반 생존 지표(등장인물 수)는 검증을 통과한다. 낮은 κ 태그(mood, shot_type)는 주요 효과가 아니라 낮은 가중의 프로파일 서술용으로만 쓴다.

### 3.5 세 추가 분석과 게이트의 사전 등록

실행 전, 프로젝트 스펙(`docs/superpowers/specs/2026-07-21-paper-dataset-design.md`)에 세 분석과 판정 게이트를 사전 등록했다.

- **(A) 가사 구조** — 압축률(반복성), 제목-가사 훅 시점/횟수, 첫 후렴 시점, 컷-가사라인 동기; 결정론적 측정; 도메인 내만; 가사 라인 ≥ 8 필터.
- **(B) 히트맵 리텐션** — most-replayed 곡선의 초반 리텐션 기울기·리플레이 피크 위치/높이; K-pop 그룹 비교 + 훅 feature × 리텐션 매개 상관; 보컬로이드는 히트맵 보유 편중으로 top 내 연속 분석만.
- **(C) 프리미어 채널 내 매칭** — 같은 채널의 프리미어 vs 비프리미어 매칭으로 채널 수준 교란 통제; log(조회/구독) 쌍대 Wilcoxon.

**게이트(사전 설정):** 세 분석 중 하나 이상에서 BH-FDR q<0.05 **그리고** |Cliff's δ| ≥ 0.33, *또는* 매칭 설계 p<0.05. 판정은 **FAIL**이었다(`docs/reports/2026-07-21-new-analyses-gate.md`). 셋을 음성/방법 결과로 보고한다(§4.3). 중간층 표본 단조성(dose-response) 분석(§4.5)은 이 게이트 밖에서 별도로 추가된 것이다.

이진 패키징 지표(Fisher 정확검정): **썸네일 텍스트 있음** 상위 9/25 vs 하위 24/25, p<0.0001; **프리미어 공개** 13/25 vs 4/25, p=0.016(§4.3에서 재검토). 성과 높은 보컬로이드 MV는 낮은 것보다 약 4배 빠르게 편집된다(23.9 vs 5.5 컷/분).

**견고성.** 채널 다작 교란이 존재한다 — 하위 그룹 채널의 영상 수가 훨씬 많고(채널 영상 수 δ −0.752), 구독자수는 균형(δ +0.187, p=0.26)이라 비율 정규화가 작동함을 보인다. log-다작 쌍대 매칭 재분석(`docs/reports/2026-07-17-confound-reanalysis.md`)에서 **검정 10개 전원이 매칭 후에도 유의**했다(예: 분당 컷 쌍별 중앙 차이 +15.0, p<0.0001; 샷 길이 중앙값 −3.98초, p=0.0003). 즉 이 효과들은 다작만으로 설명되지 않는다(잔여 불균형 존재, 매칭 쌍 배율 중앙 3.80배).

**구성개념 구조.** 편집 리듬 지표들은 서로 무관한 열 개의 우연이 아니다 — 블록 내 평균 |ρ| = 0.69, 즉 하나의 잠재 '편집 템포' 요인(`docs/reports/2026-07-21-feature-structure.md`). 편집 템포는 화면 구성(인물·채도·밝기)과 ρ = +0.27(p=0.0078)로 동반하지만, 무텍스트 썸네일과는 약하게만 연결된다(ρ = +0.10, p=0.35). 상관 구조는 도메인 간 재현된다(보컬로이드 vs K-pop PC1 로딩 congruence = 0.96). 각 극단 표본 전체(이분 분할 아님)의 순위 상관에서 편집 템포는 log 조회/구독과 보컬로이드 ρ = +0.52(p=0.0001, n=50), K-pop ρ = +0.29(p=0.0525, n=45)로 함께 움직인다.

### 4.3 세 사전등록 분석 (게이트: FAIL) — 음성 결과와 자기교정

**(A) 프리미어 반전 — 교란 통제 사례 연구.** 사이클 1 극단 그룹 비교에서 프리미어 공개가 상위에 몰렸다(13/25 vs 4/25, Fisher p=0.016; §4.1). 이를 제대로 검정하기 위해 *같은 채널 안에서* 프리미어와 비프리미어 영상을 매칭했고(최근접 업로드일 ≤ 180일), 극단 그룹 통제 집합을 오염시켰던 비-MV 콘텐츠(응원법·콘셉트 클립·라이브)를 먼저 제거했다. 보컬로이드 55쌍에서 효과는 **소멸**했다: 쌍대 Wilcoxon p=0.46, 프리미어/비프리미어 배율 중앙 1.07×(`docs/reports/2026-07-21-premiere-matching.md`). 이를 자기교정으로 제시한다 — 원 프리미어 "발견"은 프리미어의 속성이 아니라 채널 수준 교란으로 읽는 편이 낫다. (K-pop 30쌍 버전은 p=0.0022, 배율 3.31×였으나 **제외** — 레이블 메가 채널이 여러 아티스트를 호스팅하므로 채널 내 매칭으로 팬덤을 동일화할 수 없다; §5.)

**(B) 가사 반복성 — 여기서는 성립하지 않는 문헌 가설.** Nunes et al.(2015)을 언어 무관 압축률로 검정했다. 분석 전, 사용된 ASR 언어필터 측정 버그(`asr_to_lines`가 sung English 라인을 환각으로 오분류해 폐기)를 발견·수정했으며, 이것이 K-pop 가사 커버리지를 억제하고 있었다. 수정(라틴 문자 인정 + 연속중복 접기)으로 K-pop 유효 커버리지가 **50편 중 28→47**로 복구됐다(보컬로이드는 47/50로 불변). 수정된 측정에서 압축률 효과는 이전 δ +0.32에서 δ **+0.14**로 **축소**됐다(보컬로이드 상/하 0.524/0.499, p=0.41, q=0.83; K-pop 0.470/0.445, p=0.41, q=0.44) — 초기 신호는 소표본 잡음이었을 가능성이 크다. 출처별 민감도 검사도 약함에 동의한다(보컬로이드 OCR만 δ +0.28, p=0.15; K-pop ASR만 δ +0.05, p=0.78). 컷-가사라인 동기 지표가 가사 계열 최대 효과였으나 여전히 비유의였다(보컬로이드 δ +0.31, p=0.077; K-pop δ +0.28, p=0.11). 어느 도메인에서도 가사 지표가 q<0.05에 도달하지 못했다(`docs/reports/2026-07-21-lyrics-structure.md`). 측정을 고치자 기대했던 효과가 *줄었다*는 공개가 핵심이다 — 망가진 측정기를 통한 확증편향을 막아준다.

**(C) 히트맵 리텐션 — 그룹 차이 null.** 히트맵 보유 K-pop 부분표본(상위 25 / 하위 21)에서 most-replayed 리텐션 그룹 비교는 null이었다: 초반 리텐션 기울기 δ +0.25(p=0.16, q=0.47), 리플레이 피크 위치 δ −0.15, 피크 값 δ −0.05(`docs/reports/2026-07-21-heatmap-retention.md`). *시사적* 상관 하나 — 분당 컷 × 초반 리텐션 기울기, ρ +0.31, p=0.034(n=46) — 는 그룹 통합·히트맵 보유 선택 편향을 감안해 §5에서 기제 시사로만 논의한다.

**게이트 결과:** (A)~(C) 중 "q<0.05 그리고 |δ| ≥ 0.33, 또는 매칭 p<0.05"를 충족한 것은 없다 → **FAIL**(`docs/reports/2026-07-21-new-analyses-gate.md`). 버리지 않고 검증된 음성 결과로 보고한다.

### 4.4 장르 관습 null

여러 지표는 보컬로이드 그룹을 **가르지 않으며**, 양 극단 공통의 장르 관습이지 인기 요인이 아니다(출처: `docs/reports/2026-07-16-p5-report.md` §§3, 5.2): 가사 주제(양쪽 "이별" 최빈), 부정 정서, 1인칭 독백 대상, 곡 길이(duration δ −0.054), 통합 라우드니스(LUFS δ +0.286, 비유의, q=0.15), 라우드니스 레인지(δ −0.078), 업로드 요일/시각(upload_hour δ +0.027). 이 null들의 보고가 중요하다 — 공유된 스타일 관습을 성과 판별자로 오인하는 것을 막는다.

### 4.5 성과 계층 간 단조성(dose-response)

출처: `docs/reports/2026-07-22-monotonicity.md`. 극단 그룹 대조만으로는 효과가 성과에 따라 커지는지, 극단에서만 나타나는지 알 수 없다. 보컬로이드 중간층 그룹(§3.1)을 써서 `view_per_sub` 기준 하위 25 / 중간 25 / 상위 25 순서를 만들고, 사전 등록 편집 리듬 6개 지표 각각에 대해 단조 경향을 검정했다(계층 순위 대비 Kendall τ, BH-FDR). **6개 전부 단조성 성립**(q<0.05 그리고 중앙값 순서 일관):

| 지표 | 하위 중앙값 | 중간 중앙값 | 상위 중앙값 | Kendall τ | q (BH) |
|---|---|---|---|---|---|
| 분당 컷 수 | 5.5 | 17.5 | 23.9 | +0.429 | 0.0000 |
| 샷 길이 중앙값(초) | 6.21 | 2.52 | 1.5 | −0.483 | 0.0000 |
| 씬 수 | 15 | 50 | 51 | +0.343 | 0.0002 |
| 컷당 비트 수 | 18.9 | 8.3 | 5.3 | −0.369 | 0.0001 |
| 첫 15초 컷 수 | 2 | 2 | 5 | +0.332 | 0.0005 |
| 최단 샷(초) | 0.83 | 0.67 | 0.62 | −0.265 | 0.0042 |

6개 지표 모두 중간층이 두 극단 사이에 위치한다(예: 분당 컷 5.5 → 17.5 → 23.9). 극단 그룹 상관이 성과 계층 간 **dose-response gradient**로 격상된다. 이는 결정론적 측정기 기반의 보컬로이드 내 결과이며, 미관측 투자 캐비앳이 여전히 적용된다(§5).

## 5. 논의와 한계

**결과가 뒷받침하는 것.** 연구된 모집단 안에서, 성과 높은 MV는 더 빠른 편집 템포와 조밀한 인물 구성을 *보이는 경향*이 있다. 이 패턴은 다작 교란에 견고하고, 검증된/결정론적 측정기에 기반하며, 하나의 일관된 구성개념을 이루고, 구조적으로(어느 축이 가르는가는 아니지만) 두 번째 도메인에서 재현된다. 중간층 단조성 결과(§4.5)는 이 사슬에 한 고리를 더한다 — 편집 템포 차이는 단순한 상·하위 도약이 아니라 성과 계층을 따라 단계적으로 증가한다. 이 dose-response gradient는 콘텐츠 수준 설명과 *정합하며(consistent with)* 그것을 *강화하지만 확립하지는 않는다(strengthens but does not establish)* — 동일한 미관측 제작 투자 gradient가 같은 단조 패턴을 낳을 수도 있기 때문이다. 이는 잘된 영상의 *스타일*에 관한 서술적 규칙성이지 조작 레버가 아니다.

**극단 그룹 설계.** 상/하위 극단 표집은 전체 모집단 대비 효과크기를 부풀리고 깨끗한 연속 추론을 막는다. §4.1의 순위 상관과 §4.5의 중간층 단조성 확인은 이를 완화하지만 없애지는 못한다 — 중간층 표본은 보컬로이드 한정 25편 단일 계층일 뿐 완전한 연속 모집단이 아니다. 일반화 범위는 표집 창(2025-04~2026-04 보컬로이드 원본 채널 신곡; K-pop 공식/레이블 채널)으로 한정된다.

**미관측 교란(핵심 한계).** 우리는 제작비나 프로모션을 관측하지 못한다. 빠른 컷, 조밀한 인물 작화, 텍스트 없는 일러스트 썸네일, 프리미어 공개는 모두 제작 투자·마케팅 푸시의 프록시일 수 있다. 온라인 인기 연구(Szabó & Huberman 2010; Figueiredo et al. 2011)는 초기 프로모션·유입 구조가 관측 인기를 지배함을 보인다 — 바로 우리가 볼 수 없는 경로다. 프리미어 반전(§4.3A)은 겉보기 콘텐츠 효과 중 최소 하나가 그런 교란이었음을 구체적으로 보여준다.

**히트맵 선택 편향(정확한 수치와 함께).** 히트맵 보유 자체가 인기의 결과다 — 유튜브는 충분히 조회된 영상에만 most-replayed 곡선을 노출한다. 보컬로이드에서 히트맵은 **상위 24/25, 하위 4/25**만 존재하며(총 28/50), 그룹 비교가 불가능하다. K-pop은 낫지만 여전히 불균형(**상위 25/25, 하위 21/25**, 46/50)이다. 시사적 분당 컷 × 리텐션 상관(§4.3C)은 이 편향된 부분표본에서 그룹 통합으로 계산된 것이며, 확립된 매개 경로로 읽어서는 안 된다.

**VLM 모델 의존.** 의미 태그는 `qwen2.5vl:7b`에 의존한다. 재현성(temperature 0)은 정확성이 아니다: mood(κ 0.43)와 shot_type(κ 0.38)은 블라인드 라벨러 대비 중간~낮음이라 주요 가중을 지지 않으며, 등장인물 수는 검증됐다(ρ 0.80). 모델 교체는 블라인드 대조 재검증을 요하며, 이번 사이클에 바꾸지 않은 이유다.

**OCR/ASR 출처 교란.** 가사 텍스트는 하드자막 OCR(보컬로이드 위주) 또는 ASR(K-pop 위주)에서 나오며 계통 오차 프로파일이 달라, 가사 지표는 **도메인 내만** 비교하고 도메인 간은 절대 비교하지 않는다. K-pop 내에서도 제목-가사 지표는 구조적으로 과소 측정(로마자 영문 제목 vs 한글 가창)이라 해석에서 제외하며, 완화된 ASR 필터를 비가창 영문 내레이션이 통과할 잔여 위험이 남는다.

**K-pop 다중 아티스트 채널 구조.** 레이블 메가 채널(한 채널이 다수 아티스트 호스팅)과 유통사 채널은 채널 내 정규화 가정을 깬다: 조회/구독이 채널의 로스터 전반에 이질적이고, 채널 내 매칭으로 팬덤을 동일화할 수 없다. K-pop 프리미어 매칭 p=0.0022를 제외하고 K-pop 발견을 탐색적으로 두는 이유다.

## 6. 재현성

**스택.** 모든 것이 소비자용 GPU 한 대(16GB VRAM)에서 로컬로 돈다. 외부 API 없음(YouTube Data API·클라우드 LLM 없음). GPU 단계(VLM·demucs·whisper)는 순차 실행하며 절대 동시 실행하지 않는다. Windows 콘솔은 `PYTHONUTF8=1` 필수.

**3-명령 재현**(채널 발굴/열거로 `work/population.jsonl`을 만든 뒤):

```bash
python collect.py sample --population work/population.jsonl --out work/sample.csv   # 극단 그룹 표집
python batch.py                                                                     # 하룻밤 GPU 배치, 이어하기, 영상별 실패 격리
python p5_report.py                                                                 # Mann–Whitney U + Cliff's δ + BH-FDR 리포트
```

**데이터셋.** `dataset/features_100mv.csv`(100편 × 94컬럼, 2개 도메인), 전체 데이터 사전은 `dataset/README.md`(히트맵 선택 편향 주의·파생 컬럼 목록 포함). 공개 메타데이터와 파생 측정치만 — 미디어 파일·저작권 가사 원문 없음(가사 문자열이 아니라 파생 압축률만 공개).
