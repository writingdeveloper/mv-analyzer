# 보컬로이드 MV 제작 참고 체크리스트

근거: 2025-04~2026-04 원본 채널 신곡 상·하위 극단 50편 정량 비교
(`2026-07-16-p5-report.md`). **이 체크리스트는 "뜬 곡들의 공통 형태"이지 성공
공식이 아니다** — 항목 다수가 제작 투자 규모의 프록시일 수 있고, いよわ처럼
정반대 형태로 성공하는 작가도 있다. 자기 스타일을 버릴 근거가 아니라,
의도 없이 어긋나 있는 부분을 점검하는 용도로 쓸 것.

## 편집 리듬 (가장 강한 신호, δ 0.65~0.79)

- [ ] **분당 컷 15회 이상인가?** 상위 그룹 중앙값 23.9회 / 하위 5.5회.
      상위 25편 중 분당 10컷 미만은 2편뿐
- [ ] **샷 길이 중앙값 3초 이하인가?** 상위 1.5초 / 하위 6.2초.
      업계 통설(시청자 주의력은 샷당 3~5초)과도 부합
- [ ] **최장 샷이 20초를 넘지 않는가?** 상위 12.4초 / 하위 35.5초 —
      긴 고정 샷 하나가 이탈 지점이 될 수 있음
- [ ] **컷이 비트를 따라가는가?** 상위는 비트 5.3개당 1컷 / 하위는 18.9개당 1컷

## 도입부 훅 (첫 15초, δ +0.57)

- [ ] **첫 15초에 컷 4회 이상 들어가는가?** 상위 5회 / 하위 2회.
      YouTube 공식 가이드도 첫 15초를 승부처로 지목 (이탈 20%가 여기서 발생)
- [ ] 첫 컷까지 3초 이내인가? (상위 1.8초 / 하위 4.2초 — 참고 수준)

## 화면 구성 (δ 0.45~0.46)

- [ ] **인물이 화면에 충분히 나오는가?** 씬당 평균 등장인물 상위 1.24명 / 하위 0.95명
      — 인물 없는 풍경·오브젝트 씬 위주는 하위 그룹 패턴
- [ ] **채도가 충분한가?** 상위 0.36 / 하위 0.25 — 탈색·저채도 톤은 하위 그룹에 몰림
- [ ] 클로즈업 비중 확인 (상위 54% / 하위 33% — 참고 수준)
